## Featured Project: Glitch as a Sport Exploration

I developed an interactive web application that serves as a simulator investigating the evolutionary boundaries of competitive gaming mechanics.

*   **The Central Question:** At what precise moment does an unintended software error or programming glitch stop being a mistake and transform into a legitimate, community-sanctioned sport?
*   **The Research Foundation:** The application's logic is grounded in three real-world competitive milestones: *Wave-dashing* in Super Smash Bros. Melee, the *Backwards Long Jump* in Super Mario 64, and engine-based *Bunny Hopping*. 
*   **What You Can Do:** 
    1. Input any random object or conceptual idea into the text prompt.
    2. Advance the object through a step-by-step evolutionary narrative cycle.
    3. Use interactive judgment buttons to vote on whether the glitch is still "just a bug," "becoming a sport," or "already a sport" at that specific phase.

### Technical Details & Provenance
*   **Architecture:** Built cleanly using vanilla HTML5, CSS3 typography layouts, and functional JavaScript text replacement strings.
*   **AI Collaboration:** I leveraged AI to write the JavaScript DOM event handling that swaps user variables dynamically into the narrative stream.
*   **Deliberate Limitations:** To maintain a tightly scoped, responsive prototype, I intentionally omitted complex, branching scoring trees in favor of a clean, linear text loop. The current system relies on pre-authored structural prompts rather than fully autonomous generative text.
